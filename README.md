Task-03: Decision Tree Classifier for Customer Purchase Prediction

In this task, a Decision Tree Classifier was built to predict whether a customer will purchase a product based on demographic and behavioral data.

Dataset-
Source: UCI Bank Marketing Dataset-https://archive.ics.uci.edu/dataset/222/bank+marketing

Model Used-
Decision Tree Classifier

Tools Used:
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

Key Insights:

- Customers contacted fewer times had a higher probability of subscription.
- Job type and previous campaign outcome strongly influenced predictions.
- The Decision Tree model helps explain customer behavior clearly.

Results:
The model achieved good accuracy and provided interpretable decision rules for customer behavior.
